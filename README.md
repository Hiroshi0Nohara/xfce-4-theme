## How to install
1. Clone or download this repository.
2. Copy the theme folder(s) you want into `~/.themes` (create the directory if missing).
3. Copy any icon themes you want into `~/.icons` (create if missing).
4. Open XFCE Settings → Appearance and Window Manager to apply the theme.
5. For dotfile-specific instructions, check the README inside the corresponding theme or dotfiles folder.
